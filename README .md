 Task 2 - Phishing Email Analysis

## Objective

The objective of this task is to identify phishing characteristics
in a suspicious email sample.

## Activities Performed

1. Examined the sender email address.
2. Checked the email headers.
3. Identified suspicious links.
4. Checked for urgent or threatening language.
5. Checked for mismatched URLs.
6. Checked spelling and grammar.
7. Identified social engineering techniques.
8. Prepared a phishing analysis report.

## Key Concepts

- Phishing
- Email Spoofing
- Header Analysis
- Social Engineering
- Threat Detection

## Conclusion

The email was analyzed for common phishing indicators and the
findings were documented in the phishing analysis report
